1st Project: Password Storer

This is a project to imitate popular password-storing applications such as 1Password©. The idea is that a single password can be used to control access to a list of all the passwords associated with an account. This necessitates a single password that is strong enough to prevent access to unwanted parties but simultaneously memorable enough for the user to remember itself. The project therefore had several requirements:

  • Have one long, unique password to gain access to other passwords
  • Be accessible and easy to use
  • Have extra functionality such as being able to search
  • Use SQL and a database to implement the functionality
  • Have a serviceable and relatively attractive GUI or frontend menu

To fulfil all of these requirements was quite the challenge. There were several areas which I had only ever scratched the surface of before. Making an attractive GUI was much more frustrating and fiddly than I had ever anticipated. In a way, designed a GUI is exactly like making a website and it is very easy to get it wrong. 2nd Project: Maze Generator and Solver

This project was about generating a maze and then solving it. To begin with, I had to familiarise myself with various different algorithms for creating mazes and solving them. In many ways, solving a maze is very similar to making it, so this did cut down some of the work. Having considered a few different options, I opted to go with Prim's Algorithm, which works like this:

  1. Create a grid
  2. Randomly make paths through the maze
  3. Randomly pick a start and end square
  4. Recursively find a path from the start square to the end square

For me, this was a very enjoyable project and I learned a great deal by working on it. Finding out about the algorithms used was particularly interesting, especially coming from a mathematical background. - Thomas Avant

Things went wrong all the time! There were quite a few reasons for this, but it is hard to remember them all right now (perhaps I have purged them from my mind?!?). I remember that deciding how to display the maze with Java Swing was difficult. I also remember that using stacks as the data structure for the maze cells caused NPEs to be raised every time that I ran the program and debugging this was a valuable learning exercise.
